Roadmap Fase
01
Setup & Fondasi
Project structure, auth, design system, API layer
Minggu 1–2
📁
Clean Architecture Setup
Buat struktur folder feature/data/domain/presentation. Setup analysis_options.yaml dan lint rules.
📦
Core Packages
Pasang Riverpod 2.x, Dio, Freezed, GoRouter, flutter_secure_storage, Hive.
🔐
Auth Flow (JWT)
Login screen, JWT storage, auto-refresh token, biometric login, role-based redirect.
🌐
API Service Layer
Dio client + Auth interceptor + error handler. Base response model. Retrofit code gen.
🎨
Design System
AppTheme, AppColors, AppTextStyles. Komponen reusable: button, input, card, snackbar.
⚙️
Flavor Config
Setup dev/staging/prod environment. --dart-define untuk base URL dan API keys.
02
Modul Anggota Koperasi
Dashboard, simpanan, pinjaman, angsuran, notifikasi
Minggu 3–5
📊
Dashboard Anggota
Ringkasan saldo simpanan wajib/sukarela/berjangka, total pinjaman aktif, angsuran berikutnya.
📋
Riwayat Transaksi
List dengan pagination lazy-load, filter jenis & tanggal, detail transaksi.
💰
Pengajuan Pinjaman
Form pengajuan, upload dokumen (foto KTP, slip gaji), estimasi cicilan, konfirmasi.
📅
Jadwal Angsuran
Tabel jadwal cicilan, status per angsuran, tracking sisa pinjaman.
🔔
Push Notification
FCM setup, notifikasi jatuh tempo angsuran, status pengajuan pinjaman.
👤
Profil Anggota
Data diri, nomor anggota, ubah password, preferensi notifikasi.
03
Modul Pegawai / HR
Absensi GPS, lembur, cuti, slip gaji, jadwal shift
Minggu 6–9
📍
Absensi GPS + Foto
Clock in/out dengan validasi radius 100m dari kantor, foto selfie wajib, offline queue + sync.
⏰
Pengajuan Lembur
Form lembur, approval flow (menunggu → disetujui/ditolak), riwayat per bulan, notifikasi.
🏖️
Pengajuan Cuti & Izin
Sisa cuti, form cuti, kalkulasi hari kerja, validasi overlap, approval + notifikasi.
💼
Slip Gaji
List 12 bulan terakhir, preview PDF in-app, download ke penyimpanan lokal.
🗓️
Jadwal & Shift
Kalender jadwal shift, tampilan mingguan/bulanan, info tukar shift.
📢
Pengumuman Internal
Feed pengumuman perusahaan, badge notifikasi belum dibaca, detail pengumuman.
04
Polish, Testing & Deployment
Testing, CI/CD, crash reporting, release ke store
Minggu 10–12
🧪
Unit & Widget Test
Test use cases, repository, provider Riverpod. Widget test untuk komponen kritis. Target 70%+ coverage.
🔄
CI/CD Pipeline
GitHub Actions: flutter test + analyze → build APK/IPA → deploy ke Firebase App Distribution.
📱
Release Build
Obfuscation, ProGuard rules, signing config, Play Store dan App Store submission.
🚨
Crash Monitoring
Firebase Crashlytics + Analytics. Setup alert untuk crash rate di atas threshold.
⚡
Performance Tuning
Flutter DevTools profiling, lazy loading, gambar caching, minimize rebuild widget.
📶
Offline Hardening
Final QA untuk skenario offline/fluktuasi jaringan. Sync conflict resolution.

Risiko & Mitigasi
API backend belum stabil
Endpoint Laravel mungkin berubah saat development paralel
Tinggi
Buat mock API & contract testing dari awal (Postman collection)
GPS lemah di dalam gedung
Sinyal GPS tidak akurat atau tidak tersedia di kantor tertutup
Tinggi
Toleransi radius +50m, fallback ke WiFi SSID whitelist
Pengguna tidak familiar teknologi
Beberapa pegawai/anggota senior tidak terbiasa aplikasi mobile
Sedang
Onboarding tutorial interaktif, UI sangat sederhana, hotline support
Upload dokumen besar
Foto dokumen pinjaman bisa sangat besar (>5MB)
Sedang
Kompresi otomatis ke <1MB sebelum upload, progress indicator
Offline sync konflik
Data absensi offline bisa konflik jika ada error di server
Rendah
Timestamp-based resolution, queue retry dengan backoff
