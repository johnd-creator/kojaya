# Menyelesaikan Onboarding dan Memahami Akses Anggota

## Tujuan

Membantu anggota melengkapi data awal dan memahami mengapa sebagian
fitur portal belum tersedia sebelum data divalidasi.

## Kapan digunakan

- Baru pertama kali masuk ke portal anggota.
- Beranda meminta Anda melanjutkan onboarding.
- Data dikembalikan untuk diperbaiki atau masih menunggu validasi.

## Prasyarat

- Sudah masuk menggunakan akun anggota.
- Siapkan data pribadi, kontak, identitas, keanggotaan, dan rekening
  yang diminta pada formulir.

## Langkah penggunaan

1. Buka **Onboarding** dari beranda atau menu anggota.
2. Lengkapi langkah **Data Pribadi**, **Kontak & Alamat**, **Identitas**,
   **Keanggotaan**, dan **Rekening**.
3. Gunakan **Review & Submit** untuk memeriksa kembali data sebelum
   dikirim.
4. Kirim formulir onboarding. Sebelum dikirim, perubahan masih dapat
   diperiksa dan diperbaiki.
5. Pantau status pada halaman onboarding atau beranda.
6. Jika Pengurus meminta revisi, perbarui data yang diperlukan lalu
   kirimkan kembali.

## Hasil yang diharapkan

- Data onboarding tersimpan dan terkirim untuk proses validasi.
- Status berikutnya menjelaskan apakah data menunggu Admin, menunggu
  Pengurus, memerlukan revisi, atau sudah disetujui.
- Fitur finansial terbuka setelah status keanggotaan aktif.

## Status yang mungkin muncul

- **Belum lengkap**: masih ada langkah onboarding yang belum selesai.
- **Menunggu Admin**: pendaftaran menunggu verifikasi Admin Koperasi.
- **Menunggu Pengurus**: data sudah diverifikasi Admin dan menunggu
  approval final Pengurus Koperasi.
- **Perlu Revisi**: data harus diperbaiki dan dikirim ulang.
- **Disetujui**: keanggotaan aktif dan akses portal terbuka.
- **Ditolak**: pengajuan tidak diterima; hubungi Admin Koperasi untuk
  memahami langkah berikutnya.

## Kondisi gagal

- Formulir tidak dapat dikirim → periksa kembali kolom yang wajib diisi.
- Fitur simpanan atau pinjaman belum muncul → periksa status onboarding
  dan validasi keanggotaan.
- Data perlu diperbaiki → ikuti catatan revisi sebelum mengirim ulang.

## Handoff

- Validasi data awal → Admin Koperasi.
- Approval final keanggotaan → Pengurus Koperasi.
- Pertanyaan administratif tentang status → Admin Koperasi.

## Prosedur terkait

- **Mengenal Portal Anggota** untuk peta menu setelah akses aktif.
- **Alur Pembayaran Iuran Bulanan** setelah fitur finansial tersedia.
