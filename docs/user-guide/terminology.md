# Terminologi Pusat Panduan

Daftar istilah yang dipakai konsisten di seluruh artikel pusat
panduan. Diambil dari source code dan glosarium internal.

| Istilah | Definisi |
| --- | --- |
| Pusat Panduan | Halaman in-app di `/documentation` yang menampilkan artikel sesuai peran. |
| SOT | Single Source of Truth — direktori `docs/user-guide/` adalah SOT artikel. |
| Frontmatter | Blok YAML `---` di awal file Markdown yang berisi metadata artikel. |
| TOC | Table of Contents — daftar isi yang dirender dari heading. |
| Slug | Pengidentifikasi URL artikel dalam huruf kecil dan tanda hubung. |
| Permission Mode | `all` (semua izin harus ada) atau `any` (salah satu cukup). |
| Target Role | Peran target artikel: `all`, `anggota`, `admin_koperasi`, `manajer_koperasi`, `pengurus_koperasi`. |
| Risiko | Tingkat risiko operasional: `low`, `medium`, `high`. |
| Last Reviewed Commit | SHA pendek commit tempat artikel terakhir diverifikasi. |
| Screenshot Entry | ID screenshot pipeline yang dilampirkan ke artikel. |
