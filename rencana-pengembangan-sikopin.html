📋 Scope Proyek
SIKOPIN dirancang sebagai sistem informasi terpadu untuk koperasi yang mencakup manajemen keanggotaan (data anggota, riwayat, dokumen), pengelolaan iuran (tagihan otomatis, pembayaran, laporan), dan sistem kasir (POS) untuk toko koperasi. Semua modul terintegrasi dalam satu backend API yang dapat diakses via web admin maupun aplikasi Android.
Modul Utama
👥
Manajemen Keanggotaan
Pengelolaan data anggota koperasi secara lengkap, mulai pendaftaran hingga pengunduran diri.
  • Pendaftaran & verifikasi anggota baru
  • Profil anggota + foto KTP/dokumen
  • Nomor induk anggota otomatis
  • Status anggota (aktif, non-aktif, keluar)
  • Riwayat aktivitas anggota
  • Export data ke Excel/PDF
💰
Manajemen Iuran
Sistem tagihan dan pembayaran iuran wajib, sukarela, dan simpanan anggota koperasi.
  • Jenis iuran: wajib, pokok, sukarela
  • Generate tagihan otomatis bulanan
  • Pencatatan pembayaran (tunai & transfer)
  • Notifikasi tunggakan & pengingat
  • Riwayat simpanan & pinjaman
  • Laporan keuangan per periode
🛒
POS Toko Koperasi
Sistem kasir lengkap untuk toko koperasi, support tablet sebagai mesin kasir.
  • Antarmuka kasir touch-friendly (tablet)
  • Manajemen produk & kategori
  • Barcode scanner support
  • Transaksi tunai, kredit anggota, QRIS
  • Manajemen stok & peringatan minim stok
  • Laporan penjualan harian/bulanan
📊
Laporan & Dashboard
Dashboard eksekutif dan laporan terintegrasi untuk pengurus koperasi.
  • Dashboard ringkasan real-time
  • Laporan keuangan koperasi
  • Grafik pertumbuhan anggota
  • Rekap iuran & tunggakan
  • Laporan omzet toko per periode
  • Export laporan ke PDF & Excel

Alasan Pemilihan Stack
01
Laravel + Filament = Hemat Waktu
Filament PHP menyediakan admin panel siap pakai dengan CRUD otomatis. Pengurus koperasi bisa langsung pakai dashboard web tanpa perlu membangun dari nol. Estimasi hemat 2–3 bulan development.
02
Kotlin Native = Performa Terbaik
Untuk POS yang dipakai intensif setiap hari, native Android jauh lebih responsif daripada Flutter/React Native. Jetpack Compose memudahkan UI adaptif untuk phone dan tablet dengan satu codebase.
03
Offline-First untuk POS
Room Database memungkinkan modul POS bekerja tanpa internet. Transaksi disimpan lokal, lalu disinkronisasi ke server saat koneksi tersedia — krusial untuk toko koperasi di area sinyal lemah.

Risiko & Mitigasi
● Risiko Tinggi
Koneksi internet tidak stabil di lokasi toko
Mitigasi: Implementasi mode offline-first di modul POS. Transaksi disimpan di Room DB lokal, sinkron otomatis saat online.
● Risiko Tinggi
Resistensi pengguna terhadap sistem baru
Mitigasi: Libatkan pengurus dalam UAT sejak Fase 1. Sediakan sesi pelatihan onsite dan panduan penggunaan video/PDF.
● Risiko Sedang
Scope creep — permintaan fitur tambahan
Mitigasi: Gunakan dokumen scope yang ditandatangani. Fitur tambahan masuk backlog untuk versi 2.0 agar tidak mengganggu jadwal.
● Risiko Sedang
Kompatibilitas perangkat Android beragam
Mitigasi: Target minimum API 26 (Android 8.0+). Testing di 3–4 device berbeda. Gunakan Jetpack Compose untuk konsistensi UI.
● Risiko Rendah
Keamanan data anggota & keuangan
Mitigasi: Enkripsi data sensitif, HTTPS wajib, API rate limiting, audit log, backup otomatis harian.
● Risiko Rendah
Performa saat data anggota bertambah besar
Mitigasi: Optimasi query dengan indexing, paginasi di semua list endpoint, caching Redis untuk laporan berat.
